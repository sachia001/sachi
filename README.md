| სექცია | შინაარსი |
|--------|----------|
| **გარეკანი** | ორგანიზაციის დეტალები, დირექტორი, მისამართი, კონტაქტი |
| **0. შესავალი** | მიზანი და გამოყენების სფერო |

| **2. ნორმატიული მითითებები** | ISO/IEC 17020, ISO 9000, ISO 19011 და სხვ. |
| **3. ტერმინები** | ძირითადი განმარტებები |
| **4. ზოგადი მოთხოვნები** | მიუკერძოებლობა, კონფიდენციალობა |
| **5. სტრუქტურა** | ორგ. სქემა, პასუხისმგებლობების ცხრილი |
| **6. რესურსები** | პერსონალი, კალიბრირებული აღჭურვილობა |
| **7. პროცესები** | 7-ეტაპიანი შემოწმების პროცედურა, ჩანაწერები |
| **8. მართვის სისტემა** | ხარისხის პოლიტიკა, შიდა აუდიტი, ხელმძღვანელობის განხილვა |
| **9. საჩივრები** | საჩივრებისა და სააპელაციო განხილვის პროცედურა |
| **10–13** | გამასწორებელი ქმედებები, შეუსაბამო მუშაობა, სუბკონტრაქტი, დოკ. კონტროლი |
| **დანართი A** | 17 დოკუმენტის სრული ჩამონათვალი |
